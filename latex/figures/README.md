# Figures

Store report figures in this directory. Prefer vector PDF for plots and
diagrams, and use PNG or JPEG for raster images. Include a figure with:

```tex
\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.8\linewidth]{example.pdf}
  \caption{Describe what the figure shows.}
  \label{fig:example}
\end{figure}
```
